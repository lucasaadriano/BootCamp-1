# BootCamp I

## Sobre a disciplina

Este repositório reúne os materiais, as atividades e os projetos relacionados à disciplina BootCamp I, 
do curso de Ciência da Computação. O objetivo é organizar minha trajetória acadêmica e desenvolver uma 
base para meu futuro portfólio profissional na área de Tecnologia da Informação.

## Atividades e conteúdos da disciplina

### Projeto Study Hub — Etapa Inicial

- Planejamento da identidade profissional na área de Tecnologia da Informação.
- Elaboração de uma biografia acadêmica e apresentação dos interesses profissionais.
- Identificação de áreas de interesse, como desenvolvimento de software, dados, inteligência artificial e redes.
- Planejamento da estrutura de pastas do repositório no GitHub.
- Organização das disciplinas, atividades, anotações e projetos acadêmicos.
- Elaboração de uma matriz para organizar as disciplinas e os materiais de estudo.
- Preparação de uma apresentação em vídeo sobre a proposta do projeto.

### Criação de Repositório com Versionamento — Etapa Intermediária

- Planejamento e organização dos repositórios acadêmicos e pessoais.
- Introdução ao versionamento de código utilizando Git.
- Criação de um projeto inicial de página web e registro da versão 1.0.
- Realização de alterações no código e envio das atualizações para o GitHub.
- Organização dos projetos em pastas e elaboração de arquivos README.md.
- Publicação de uma página web utilizando GitHub Pages.
- Compartilhamento dos projetos e integração com o perfil profissional do LinkedIn.
- Preparação de uma apresentação em vídeo de aproximadamente cinco minutos sobre o portfólio.

## Ferramentas e plataformas

- Git — controle de versões dos arquivos.
- GitHub — hospedagem e organização dos repositórios.
- GitHub Desktop — gerenciamento visual dos repositórios.
- GitHub Pages — publicação da página web.
- LinkedIn — divulgação do portfólio profissional.

## Objetivo do repositório

Centralizar as atividades e os projetos da disciplina, documentar o aprendizado e acompanhar
minha evolução acadêmica e profissional durante o curso de Ciência da Computação.
