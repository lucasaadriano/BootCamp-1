## 4. Sobre o GitHub

O GitHub é uma plataforma que hospeda repositórios Git. O Git é um sistema de controle de versão: ele registra o histórico de alterações feitas nos arquivos de um projeto. Cada alteração registrada é um commit, salvo com data, autor e descrição, o que permite consultar versões anteriores e acompanhar a evolução do trabalho.

Neste projeto, o GitHub tem três funções:

- **Centralizar o material:** os arquivos das duas fases ficam reunidos em um único repositório.
- **Registrar a evolução:** o histórico de commits mostra como o projeto foi construído, da Fase 1 à Fase 2.
- **Servir de portfólio:** o repositório já faz parte da minha presença profissional em TI, o que se conecta diretamente ao tema do projeto.
